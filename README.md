# 添田 美帆 ポートフォリオ

日本語の1ページサイト。React / TypeScript / Viteで制作し、公開HTMLに本文も事前出力します。JavaScriptが失敗しても本文・料金・外部リンクが残ります。

## 主なファイル

- `src/data/site.ts`: 名前、プロフィール、URL、サービス、価格、口コミ、制作経験、写真を一元管理。
- `src/data/types.ts`: サービス等のデータ形式。
- `src/App.tsx`: 各セクション、料金詳細、モバイルメニュー。
- `src/index.css`: 色、文字、レイアウト、スマホ表示、動きを減らす設定。
- `src/data/seo.ts`: ページ情報と公開URL。本人限定状態は検索対象外。
- `scripts/prerender.tsx`: 本文入りHTMLと検索用ファイルを生成。
- `public/images/miho-*.webp`: 提供された本人写真をサイズ別に最適化。
- `shots/`: 検品結果と画面キャプチャ。

## 起動・更新

`npm install` → `npm run build` → `npm run preview`。

検品はプレビュー起動中に `npm run verify`。Windowsの制限環境向けブラウザー起動設定は `scripts/verify-environment.mjs` に分離し、スキル同梱の `shots/verify.mjs` は変更していません。

## 制作事例を追加する

作品は src/data/works.ts、画像は public/images/works/ で管理します。詳しい記述例、削除・並べ替え・初期表示件数は「制作事例の更新方法.md」を参照してください。現在は0件で非表示です。

## 写真

ご依頼により、内蔵画像編集で余白のトリミングと明るさ調整を行った写真に差し替えました。PC・スマホとも編集後の画像全体を表示し、追加のトリミングを行いません。元写真のWebPも保管しています。

## 公開範囲

初期の本人限定公開を維持しています。名刺に使う際は、サイトの閲覧範囲を一般公開に変更する必要があります。一般公開後に検索対象とする場合は `SITE_PUBLIC=true` を設定して再ビルドします。

## 制約

フォームは指定Googleフォームへのリンクです。独自送信APIはありません。実際のフォーム送信は検品で行いません。掲載していない実績・成果・顧客名は創作していません。料金の税込・税別は未指定のため明記していません。
